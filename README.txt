Viloyatga Boramiz - Project Files

Files:
- index.html: website
- assets/Man waiting car.webm: intro video asset

How to run:
1. Keep index.html and the assets folder together.
2. Open index.html in a modern browser. For geolocation and some browser features, use a local web server (for example VS Code Live Server) or HTTPS rather than file://.
3. An internet connection is needed for external map/globe libraries, map tiles, and geocoding.

Important:
This is a front-end prototype. Profile, announcements, and requests are stored in the browser's local storage; they are not shared between different users/devices because no backend server/database is connected.
